# Berkontribusi

1. Jelaskan masalah atau ide melalui issue, termasuk halaman terkait dan perilaku yang diharapkan.
2. Buat branch untuk perubahan, lalu jalankan aplikasi dengan panduan XAMPP di README.
3. Pertahankan identitas visual, dukungan HP, label formulir, akses keyboard, dan reduced motion.
4. Jalankan `npm test` untuk perubahan backend dan `npm run build` untuk memastikan aplikasi dapat dibangun. Periksa alur yang berubah lewat browser.
5. Dalam pull request, jelaskan perubahan dan hasil pengujiannya. Sertakan tangkapan layar bila tampilan berubah.

Jangan memasukkan `.env`, kata sandi, dump database pengguna, `uploads/`, atau `node_modules/` ke Git. Gunakan data buatan untuk pengujian. Perubahan struktur database harus menyertakan cara migrasi tanpa menghapus data yang ada.
